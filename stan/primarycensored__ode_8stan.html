Log CDF of the primary distribution on [0, pwindow]

Returns log F_primary(p) for the primary event time p in [0, pwindow]. Only primary_id values supported by check_for_analytical should be passed here. The Stan _lcdf convention requires the | syntax at call sites.

Parameters
pPrimary event time in [0, pwindow]
primary_idPrimary distribution identifier (1=uniform, 2=expgrowth)
primary_paramsDistribution parameters (empty for uniform; [r] for expgrowth)
pwindowPrimary event window width
Returns
log(F_primary(p))
