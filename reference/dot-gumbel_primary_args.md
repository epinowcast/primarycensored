# Location and scale of a truncated Gumbel primary

Location and scale of a truncated Gumbel primary

## Usage

``` r
.gumbel_primary_args(object)
```

## Arguments

- object:

  A `primarycensored` object as created by
  [`new_pcens()`](https://primarycensored.epinowcast.org/reference/new_pcens.md).

## Value

List with `mu` and `beta`, after checking that they are valid single
numbers.
