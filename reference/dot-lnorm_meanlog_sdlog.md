# Lognormal delay meanlog and sdlog of a pcens object, defaulting as in [`stats::plnorm()`](https://rdrr.io/r/stats/Lognormal.html)

Lognormal delay meanlog and sdlog of a pcens object, defaulting as in
[`stats::plnorm()`](https://rdrr.io/r/stats/Lognormal.html)

## Usage

``` r
.lnorm_meanlog_sdlog(object)
```

## Arguments

- object:

  A `pcens` object.

## Value

A list with `meanlog` and `sdlog`.
