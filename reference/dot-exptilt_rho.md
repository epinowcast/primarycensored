# Tilt of the exponentially tilted primary of a pcens object

Tilt of the exponentially tilted primary of a pcens object

## Usage

``` r
.exptilt_rho(object)
```

## Arguments

- object:

  A `primarycensored` object as created by
  [`new_pcens()`](https://primarycensored.epinowcast.org/reference/new_pcens.md).

## Value

The tilt `r`, a single finite number.
