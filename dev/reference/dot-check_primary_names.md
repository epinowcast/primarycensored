# Check that the primary density and CDF refer to the same distribution

Check that the primary density and CDF refer to the same distribution

## Usage

``` r
.check_primary_names(d_name, pprimary)
```

## Arguments

- d_name:

  Name of the primary density function, as given by
  [`.dist_name()`](https://primarycensored.epinowcast.org/dev/reference/dot-dist_name.md).

- pprimary:

  The primary CDF function.

## Value

`NULL` invisibly. Called for its error.
